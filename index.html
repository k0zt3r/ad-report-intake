AD Report Intake

Отчёт об ИС → проверенные признаки Active Directory → вектор и JSON для будущего агента.

1. Загрузить отчёт

Поддерживаются TXT, MD, DOCX и PDF с текстовым слоем; до 10 МБ. Файл обрабатывается на этом компьютере. Сканированные PDF пока не распознаются.

2. Контекст ИС

Загрузите отчёт, чтобы увидеть найденные сведения.

3. Проверить извлечённые признаки

Автоматические выводы требуют проверки. Изменения здесь пересчитывают оценку; в JSON они отмечены как ручные.

Загрузите отчёт, чтобы увидеть признаки.

4. Вектор и сценарии

Оценка от 0 до 1 отражает состояние мер защиты. В каждом направлении и сценарии берётся минимальная оценка применимых признаков. При неизвестных признаках показывается интервал.

Границы прототипа. Правила извлекают только явно сформулированные сведения. Отсутствие записи в отчёте означает «неизвестно». Это экспертная оценка для планирования проверки, а не вероятность компрометации. Источник и исходный текст доказательства остаются в экспорте.
